## 明确的限制

- 官方 CI 拉取 `servicewechat.com/wxa/ci/getwhiteextlist` 时被当前环境的网络规则阻止（403）；工具使用内置规则继续，最终编译命令退出为 0。环境配置草稿已补充所需域名，保存草稿本身不会立即改变当前网络规则。
- 当前 CI 包的原生 WXML / WXSS 插件仅提供 Windows / macOS 入口，在 Linux 无法执行该插件；已通过上述官方旧版 Linux 编译器补充验证。模板编译和渲染树生成不等于当前微信版本的界面显示、手势、键盘或真机验证。
- 云服务逻辑在内存事务和 SDK 适配模拟中通过；用户尚未注册小程序，真实云集合、权限、微信身份绑定和远端数据库事务未部署验证。
- SDK 上游间接依赖的审计通报仍存在，详见部署说明；未通过跳过 TLS、签名、校验或修改依赖包内容来安装。

现在可以按 `docs/web-demo.md` 在本机浏览器运行，也可在 Windows / macOS 的微信开发者工具中导入源码体验。得到 AppID 后，按 `docs/wechat-setup.md` 完成实际云服务和两台设备验证，再上传体验版。

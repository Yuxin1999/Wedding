# 已有 AppID：让两个人在微信里一起备婚

你已经有小程序 AppID，可以从这里开始。先做供你们两个人使用的**体验版**；正式公开发布另外需要提交微信审核。仓库中的协作代码已具备，跨手机同步需要你在自己的微信账号下完成云开发配置。

## 1. 下载最新代码，使用你的 AppID

1. [下载 GitHub 最新源码 ZIP](https://github.com/Yuxin1999/Wedding/archive/refs/heads/main.zip) 并解压。
2. 用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入包含 `project.config.json` 的仓库根目录。
3. 使用你已注册的小程序 **AppID**，把 `project.config.json` 中的 `"appid": "touristappid"` 改成自己的 AppID。使用有该小程序开发权限的微信登录。

不用启动 Web Demo，也不用前端“构建 npm”。AppID 是项目标识，不要在仓库填写 AppSecret、微信登录凭证或上传私钥。

## 2. 开通微信云开发

1. 在微信开发者工具中打开“云开发”，按页面提示为这个小程序开通环境。环境套餐及费用以微信当前控制台为准，确认适合自己后再开通。
2. 复制**环境 ID**，不是环境显示名称。
3. 修改 `miniprogram/config.js`：

   ```js
   module.exports = { cloudEnv: '这里替换成你的完整环境ID' };
   ```

两个人使用同一个小程序、同一个环境。另一半不需要创建云环境或注册小程序。

## 3. 创建三个集合并部署云函数

在云开发的“数据库”里创建三个集合，名称必须一致：

| 集合名称 | 存储内容 |
| --- | --- |
| `wedding_users` | 微信用户和共同空间的绑定 |
| `wedding_spaces` | 两人的婚期、清单、分类、预算和版本信息 |
| `wedding_invites` | 邀请码摘要和有效期 |

每个集合的客户端权限都设为**所有用户不可读写**。若使用自定义规则，填写：

```json
{ "read": false, "write": false }
```

应用通过云函数读写。云函数会确认真实微信身份及两人绑定关系，因此无需把数据库设成公开读写。

然后在开发者工具中：

1. 给 `cloudfunctions` 目录选择刚开通的云环境。
2. 右键 `cloudfunctions/wedding`，选择**上传并部署：云端安装依赖**（入口名称以当前工具为准）。上传整个文件夹，包括 `domain.js`、`service.js` 和 `package-lock.json`。
3. 等待部署成功，确认云函数名为 `wedding`。使用云开发当前支持的 Node.js 18 或更新运行时。
4. 重新编译。进入“我们”，应出现“创建 / 连接共同空间”和加入入口。

若仍显示“同步待开通”，先检查 `config.js` 是否保存、环境 ID 是否完整、是否已重新编译。若创建空间报错，查看 `wedding` 云函数日志，确认三个集合和依赖均已部署到同一个环境。

## 4. 上传为体验版，给另一半访问权限

1. 在开发者工具右上角点**上传**，填写版本号（例如 `0.2.0`）和说明（例如“双人备婚协作”）。上传成功表示代码进入微信后台，尚未正式公开发布。
2. 登录[微信公众平台](https://mp.weixin.qq.com/)，进入这个小程序的**版本管理**，找到刚上传的开发版本，选择**设为体验版**。
3. 到**成员管理 → 体验成员**，按后台提示添加另一半的微信号并完成确认；你也需要具有开发或体验权限。
4. 在版本管理找到**体验版二维码**，让双方扫码打开同一版本。

体验版适合先给指定成员试用。后台若提示需要先完成主体资料、认证、备案或其他资格，请按该 AppID 当前要求完成；添加体验成员不会绕过平台要求。

## 5. 只创建一个共同空间，再邀请另一半

1. **你操作**：在“我们”中填写双方实际称呼，点“创建 / 连接共同空间”。首次创建会把你当前手机的本机计划复制到云端。
2. 点“邀请我的伴侣”，然后点“发邀请卡片给伴侣”，在微信的分享界面选另一半。也可以复制 12 位邀请码，自己发给对方。
3. **另一半操作**：打开邀请卡片，核对预填的邀请码并点“一起开始准备”；或进入同一体验版的“我们 → 已有伴侣的邀请码？点此加入”，手动输入邀请码。
4. 加入后，“我们”页显示两位成员已加入。双方都能编辑婚期、清单、分类、预算、事项关联和付款日期。点成员卡片可查看分给该成员的待办。

**不要两个人分别创建各自的共同空间。** 另一半应选择“加入”。本版不提供解绑或切换伴侣；如果已经误建两个空间，请先备份计划并查看云端数据，再处理绑定，不要直接清空数据库。

邀请卡片和邀请码有效期为 7 天，仅允许另一位成员加入；重新生成后旧卡片和旧码失效。如果体验阶段卡片打不开，先扫码进入该体验版，再手动输入邀请码。分享卡片不会自动加入，仍需对方确认。

加入保留另一半设备原有的本机记录，但不会把两份清单自动合并。“查看保留的本机计划”只切换显示，不会退出双人绑定。

## 6. 用两台手机验证

- 你把一件事项分配给另一半；对方打开清单或等待约 15 秒应看到更新。成员卡片可筛选各自的待办，“一起准备”显示共同任务。
- 对方新增一笔预算、绑定事项并设置付款日期；你应能看到金额和关联。最近更新提示显示哪位成员更新了哪一类计划。
- 页面前台每 15 秒检查更新；编辑表单时暂停，切换页面或进入后台停止旧页面定时器。需要立即更新时点“刷新”或下拉。
- 两人同时打开同一旧记录编辑时，先保存的一方成功；后保存的一方看到冲突提示，输入会保留。核对另一半的更新后再决定如何保存。
- 断网时应提示同步或保存失败；不会显示虚假的已保存，也不会把云端修改偷偷写成本机记录。

自动同步会使用云函数和数据库额度，可以在云开发控制台查看用量。付款提醒目前只在小程序内显示，不会在关闭小程序后主动发送微信通知。

## 7. 想正式发布时

在微信公众平台完善小程序名称、图标、介绍、服务类目、主体与备案信息、用户隐私保护指引等当前要求。到“版本管理”提交审核，审核通过后由管理员点击发布。正式版发布后，也仍需按第 5 步完成你们的共同空间绑定。

后续更新需要区分两件事：修改小程序页面后重新上传体验版或发布；修改 `cloudfunctions/wedding` 后也要重新部署云函数。**上传小程序不会自动部署云函数。** 双方应使用同一最新版客户端。

本工作区已验证代码和模拟双人流程，尚未连接你的真实云环境，也没有替你上传、付费开通或发布。实际微信分享、两台真机同步和体验版权限需按上述步骤验证。
